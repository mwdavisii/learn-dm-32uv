# Channel

A single pre-programmed configuration of: RX frequency, TX frequency, mode (analog FM or DMR), bandwidth, tone ([ctcss](ctcss.md) / [dcs](dcs.md)) or [color-code](color-code.md) and [talkgroup](talkgroup.md) for DMR, power level, scan inclusion, and TX-enable/disable.

On the DM-32UV, spinning the channel knob within a [zone](zone.md) moves between channels. Each "channel" is one entry in the [codeplug](codeplug.md) — a row in the channels CSV.

For a [repeater](repeater.md), one codeplug channel typically holds both the repeater's output frequency (RX) and its input frequency (TX, which differs by an offset). For [simplex](simplex.md), TX and RX match.

See: [zone](zone.md), [simplex](simplex.md), [duplex](duplex.md), [repeater](repeater.md)
